# Development Roadmap

## Milestone 1: Foundation

- React dashboard shell
- FastAPI backend
- PostgreSQL schema
- Demo market, prediction, risk, and paper trading APIs
- Documentation

## Milestone 2: Market Data

- Choose country and asset class
- Integrate a market data provider
- Store historical OHLCV candles
- Stream or poll quotes

## Milestone 3: Indicators

- SMA, EMA, RSI, MACD, VWAP, Bollinger Bands
- Indicator API and chart overlays

## Milestone 4: Paper Trading

- Virtual balances
- Simulated orders
- Positions and P/L
- Trade journal

## Milestone 5: Backtesting

- Historical strategy tests
- Win rate, profit/loss, Sharpe ratio, max drawdown
- Strategy comparison

## Milestone 6: AI and News

- News ingestion
- Sentiment scoring
- Baseline ML model
- Confidence and explainability

## Milestone 7: Broker Integration

- Broker adapter interface
- Paper broker parity
- Manual approval mode
- Live trading controls and audit review
